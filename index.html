AutoReportR analyse automatiquement votre jeu de données (types de variables, statistiques descriptives, valeurs manquantes) et génère un rapport HTML clair, prêt à partager.

> auto_report(mes_donnees)

Ce que fait AutoReportR

Les étapes répétitives d'une analyse univariée, réalisées automatiquement et réunies dans un seul rapport.

Typage automatique

Chaque variable est reconnue comme numérique ou catégorielle, sans configuration.

Statistiques descriptives

Effectif, moyenne, médiane, écart-type, minimum, maximum ; effectifs, pourcentages et mode pour les variables qualitatives.

Valeurs manquantes

Nombre et pourcentage de valeurs manquantes par variable, taux de complétude global.

Synthèse et points clés

Détection des asymétries, des fortes dispersions, des modalités dominantes ou ex æquo.

Interprétations par IA

En option, une interprétation rédigée de chaque variable grâce à l'API Groq (Llama 3.3).

Rapport HTML

Un fichier unique, lisible sur ordinateur et sur mobile, à ouvrir ou partager directement.

Installation

Le package s'installe directement depuis GitHub.

1

Installer le package remotes (une seule fois)

install.packages("remotes")
2

Installer AutoReportR depuis GitHub

remotes::install_github("alinkpessostalec9-creator/AutoReportR")
3

Charger le package

library(autoreportr)
Dépendances : httr, jsonlite et readxl sont installés automatiquement avec le package.

Utilisation

Une seule fonction à retenir : auto_report().

# 1. Analyse complète d'un jeu de données auto_report(iris) # 2. Avec un titre et un auteur personnalisés auto_report(iris, title = "Analyse des iris", author = "Votre nom") # 3. Sur une sélection de variables auto_report(iris, vars = c("Sepal.Length", "Species")) # 4. Générer le rapport sans l'ouvrir automatiquement fichier <- auto_report(mtcars, open_report = FALSE)

Ce que vous voyez dans la console

Interprétations par IA (optionnel) : définissez votre clé API Groq avant de lancer auto_report(), avec Sys.setenv(GROQ_API_KEY = "votre_cle"). Sans clé, le rapport est généré normalement, sans les interprétations rédigées. Une connexion Internet est nécessaire.

Fonctions disponibles

La fonction principale s'appuie sur des fonctions utilisables séparément.

FonctionRôle
auto_report(data, vars, title, author, open_report)Génère le rapport HTML complet et renvoie le chemin du fichier.
check_data(data)Vérifie le jeu de données (nombre d'observations et de variables).
detect_types(data)Détecte le type de chaque variable (numérique ou catégorielle).
analyze_missing(data)Compte les valeurs manquantes par variable et au total.
compute_descriptive_stats(data)Calcule les statistiques descriptives de chaque variable.
